DEALERSHIP PROJECT: January 2025 - May 2025
Course: CS210 - Intermediate Computing
Language: Java

Project Description: Once completed, the system will be able to do support the following functionality.
There are two types of users (roles) that the system supports: managers, and salespersons.
Each role is limited to a set of functions, which will be explained shortly. Upon starting up,
the system initializes itself and present the user with a login menu, which allows the user to
login to the system as a manager or as a salesperson. After making a selection, the user
authenticate him/herself by entering a username and a password. Once authenticated,
each type of user is presented with a menu of options, which include every operation that
the user is allowed to perform.
The following is a list of things that managers and salespersons can do.
Manager
• Update Inventory: Add or delete cars
• Generate reports: Inventory Reports and Sales Reports
Salesperson
• Search Inventory: Retrieve car records based on various properties of the cars
• Status Updates: Change vehicle status or sell a vehicle

Data Structures Implemented: ArrayLists, HashMaps, HashSets
